# 大勇士小英语 🦸

面向小学生的英语学习闯关小游戏（手机网页版）。

## 这是什么
- 用「听一听 → 跟读 → 排一排 → 记一记」4 关闯关的方式学习英语小短文
- 内容为原创短文，由易到难，覆盖校园生活、AI 机器人等主题
- 有星星、称号、连续打卡、排行榜等激励
- 完成任意一关自动打卡，无需手动
- 预置 10 个测试账号（stu01 ~ stu10），点头像即可进入
- 系统美式发音朗读
- 素材图片来自桌面「儿童英语素材」，已压缩放入 images/ 目录

## 怎么运行
直接用浏览器打开 `index.html` 即可（推荐手机浏览器 / 微信里打开）。

或者本地起一个静态服务：
```
python -m http.server 8000
```
然后访问 http://localhost:8000

## 怎么部署（免费）
这是一个纯静态网页，可以部署到任意免费静态托管：
- Vercel / Netlify / Cloudflare Pages / GitHub Pages 都可以
- 部署后得到一个链接，分享给别人就能打开

## 数据说明（重要）
- 当前 MVP：每个学生的进度存在**手机本地**（浏览器 localStorage）
- 排行榜目前只统计**本机**上登录过的账号
- 以后接入线上后端 + 数据库后，数据会变成云端同步，所有同学共享
- 切换数据源时只需要修改 `js/storage.js`，页面代码不用动

## 目录结构
```
index.html        页面入口
css/style.css     样式（明亮卡通风）
js/data.js        账号、称号、主题与短文内容（在这里加新短文）
js/storage.js     数据存储层（以后接云端只改这里）
js/app.js         页面与闯关逻辑
images/           素材图片（来自桌面「儿童英语素材」）
预览截图/          各页面效果预览图
```
